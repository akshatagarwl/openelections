<section id="review" className="dark prose-invert">

## Review is not scrutiny

The announced IIT/IIIT review is useful. It answers a different question.

|               | Institutional review | Public scrutiny   |
| ------------- | -------------------- | ----------------- |
| Who looks     | Appointed reviewers  | Anyone            |
| What they see | What they are given  | What is published |
| Findings      | Go to the Commission | Visible to all    |
| Reproducible  | By other appointees  | By anyone         |
| Each release  | If re-commissioned   | Continuously      |

</section>
